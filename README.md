## PT-BR

## Visão Geral

O ChatBoot é um laboratório prático de Python para construir um chatbot acessível com interface web, integração com IA, recursos de voz e persistência de conversas.

## Problema que o projeto resolve

Projetos de estudo muitas vezes ficam apenas na teoria e não viram portfólio aplicável.  
O ChatBoot resolve isso com trilhas práticas, mini projetos progressivos e foco em problemas reais de acessibilidade, arquitetura e entrega.

## Diferenciais

- Chat online com amigos
- API nvidia
- Trilha estruturada com evolução incremental.
- Mini projetos com escopo claro.
- Foco em acessibilidade (voz, teclado, contraste).
- Integração de Python, Flask, IA e banco de dados.
- Documentação bilíngue para colaboração.

## Quem este projeto ajuda

- Pessoas iniciantes/intermediárias em Python.
- Quem quer aprender IA aplicada em contexto real.
- Quem busca portfólio técnico com entregas concretas.
- Comunidade interessada em inclusão digital.

## Por que fiz este projeto

- Consolidar fundamentos de Python com prática contínua.
- Evoluir de scripts simples para arquitetura web organizada.
- Aprender IA, NLP e acessibilidade de forma aplicada.
- Criar base para novos mini projetos no ecossistema Habitat Python.

## O que serei capaz de fazer ao concluir

- Criar chatbots com Python e Flask.
- Integrar APIs/modelos de IA.
- Persistir histórico de conversas em SQL.
- Adicionar entrada por voz e saída em áudio.
- Aplicar princípios de acessibilidade web.
- Publicar uma aplicação funcional em nuvem.

## Desafios e problemas reais a resolver

1. Tornar a interface 100% navegável por teclado.
2. Garantir fallback quando IA externa falhar.
3. Armazenar e recuperar contexto de conversa.
4. Medir qualidade de respostas com métricas.
5. Comparar modelos de linguagem por latência/custo.
6. Implementar autenticação e proteção de rotas.
7. Preparar deploy com configuração de ambiente.
8. Criar base de testes para manter qualidade.

## EN

## Overview

ChatBoot is a practical Python lab to build an accessible chatbot with a web interface, AI integration, voice features, and conversation persistence.

## Problem this project solves

Learning projects often stay theoretical and do not become practical portfolio pieces.  
ChatBoot solves this with structured tracks, progressive mini projects, and focus on real-world accessibility and engineering problems.

## Key differentiators

- Structured roadmap with incremental evolution.
- Mini projects with clear scope.
- Accessibility-first approach (voice, keyboard, contrast).
- Integration of Python, Flask, AI, and databases.
- Bilingual documentation for collaboration.

## Who this helps

- Beginner/intermediate Python learners.
- Developers learning applied AI in realistic scenarios.
- People building a strong technical portfolio.
- Communities focused on digital inclusion.

## Why I built this project

- To strengthen Python fundamentals through consistent practice.
- To evolve from scripts to maintainable web architecture.
- To learn applied AI, NLP, and accessibility.
- To create a foundation for new mini projects in Habitat Python.

## What I will be able to do after completion

- Build chatbots with Python and Flask.
- Integrate AI APIs/models.
- Persist and query conversation history in SQL databases.
- Add speech input and audio output.
- Apply accessibility principles in web apps.
- Deploy a working app to cloud platforms.

## Challenges and real problems to solve

1. Make the UI fully keyboard accessible.
2. Provide reliable fallback when external AI fails.
3. Store and recover conversational context.
4. Measure response quality with useful metrics.
5. Benchmark language models for latency/cost.
6. Implement authentication and route protection.
7. Prepare production-like deployment configuration.
8. Add tests to maintain software quality.
